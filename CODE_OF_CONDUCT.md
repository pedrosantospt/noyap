# Code of Conduct

## Standard

Be direct, respectful, and useful.

No harassment, threats, personal attacks, doxxing, spam, or bad-faith disruption.

Technical disagreement is welcome. Make it concrete:

- cite the file, behavior, benchmark, or source
- explain the impact
- propose a fix when practical

## Scope

This applies to repository issues, pull requests, discussions, benchmark submissions, and maintainer communication.

## Enforcement

Maintainers may edit, hide, lock, or remove contributions that violate this standard. Repeated or severe violations may lead to blocking from the project.

## Reporting

Report conduct issues privately to the maintainer if possible. If private reporting is not available, open an issue with the minimum necessary detail.
